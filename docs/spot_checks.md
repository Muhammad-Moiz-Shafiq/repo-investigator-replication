# Spot checks on github.com

My other checks compare code with the database. These compare the database with GitHub itself.
For each row I open the link, look at the one thing listed, and write ok or what differs. Times are in UTC and in PKT (UTC+5), my local time.

Generated by scripts/answer_keys/make_spot_checks.py. Small time differences of a few seconds are fine.

Round 1 (checks 1 to 17, R1 to R10). I checked all 17 rows on github.com on 2026-10-22. All matched. The pages show dates but not exact times, so I also compared the exact times of every row with the GitHub API: CI run start, result and attempt; PR opened, merged and every review; issue opened and closed; commit time. All matched to the second.

Round 2 (checks 18 to 23, R11 and R12, added when I added those two templates). I checked all 6 on github.com on 2026-10-22. All matched. I also compared them with the GitHub API (PR author, opened, merged and closed times, titles, lines added and deleted). All matched. Because these three commits were small, I also compared the size of 30 random commits (2 to 1,741 lines) with the API. All matched.
